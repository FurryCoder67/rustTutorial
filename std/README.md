# Std Library Types Folder

This folder corresponds to the Rust by Example Std Library Types chapter.

## Files

- `std.rs`
  - Contains examples of commonly used standard library types such as `String`, `Vec`, `HashMap`, `Rc`, and more.

## How it works

Rust’s standard library provides many powerful data structures and utilities. This chapter shows how to use the most important built-in types safely and idiomatically.

Important concepts:

- `String` and `str` handle owned and borrowed text.
- `Vec<T>` is the growable array type.
- Smart pointers like `Rc<T>` and `Box<T>` manage ownership.
- Standard library collections and utilities are designed for safety and performance.

## Learning outcomes

From this folder, you should learn:

- How to use common standard library types.
- When to choose heap-allocated versus stack-allocated collections.
- How smart pointers integrate with ownership.
- Why the standard library is the foundation for Rust application code.
