# Nth Prime

Find the nth prime number.

## Challenge

- Implement `nth` to return the nth prime, where `nth(1)` returns `2`.
- The function should handle reasonably large values of `n`.
- For invalid input like `n == 0`, the function may panic.

## Files

- `workspace.rs` — implement `nth`.
- `solution.rs` — complete implementation.

## How it works

The solution checks numbers sequentially and counts primes until it reaches the requested ordinal.

## Learning outcomes

- How to implement prime checking.
- How to generate a sequence of values under a condition.
- How to use loops and simple arithmetic efficiently.
