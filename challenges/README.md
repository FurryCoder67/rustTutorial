# Challenges

Contains Rust practice problems inspired by the Exercism Rust track.

Problems are organized by difficulty in `easy/`, `medium/`, and `hard/`. Each problem folder includes:

- `README.md` — describes the challenge and the rules.
- `workspace.rs` — starter code with an empty function or struct to implement.
- `solution.rs` — a complete reference implementation.

Use the `workspace.rs` files to practice solving the problems yourself, and consult `solution.rs` afterward for a verified implementation.
