# Expressions Folder

This folder corresponds to the Rust by Example Expressions chapter.

## Files

- `expressions.rs`
  - Provides examples of Rust expressions, operators, and the ways expressions evaluate to values.

## How it works

Expressions are the building blocks of Rust code. Every value in Rust is produced by an expression, and many constructs in Rust are expressions rather than statements.

Key ideas:

- Expressions always produce values.
- Operators and function calls are expressions.
- Blocks `{ ... }` are expressions too, and their final expression becomes the block's value.
- The distinction between statements and expressions is important for writing idiomatic Rust.

## Learning outcomes

This folder teaches:

- How to write expressions that compute values.
- How operators and blocks fit into Rust's expression grammar.
- Why Rust uses expressions for control flow and value construction.
